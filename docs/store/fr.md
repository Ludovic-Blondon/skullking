## Description (4000)

Skull Scores compte les points de vos parties de Skull King, du premier pli au podium.

La feuille de papier vous suffisait, jusqu'au moment où quelqu'un annonce 0 en manche 9, capture
le Skull King avec une sirène et réclame ses +40. Cette application connaît le barème par cœur,
additionne pour vous et laisse la table jouer.

TOUT LE BARÈME DE LA BOÎTE
• Barème classique : 20 points par pli annoncé, ±10 par carte sur une mise 0
• Variante Rascal le Flambeur, avec le potentiel de manche et le boulet de canon
• Bonus de capture : 14 de couleur, sirène contre Skull King, Skull King contre pirates
• Cartes avancées : Kraken, Baleine blanche, Butin et ses alliances
• Pouvoirs des pirates : Harry le Géant (mise ±1) et le pari de Rascal (±10 / ±20)
• Édition 2021 et éditions antérieures : le barème suit la boîte que vous avez sortie

PENSÉE POUR UNE VRAIE TABLE
• Saisie en deux temps : les annonces, puis les plis — comme la manche se joue
• Les sommes se contrôlent toutes seules : une table sur-annoncée se voit tout de suite
• Une manche mal saisie se corrige, et tous les totaux suivants se recalculent
• L'écran reste allumé pendant la partie
• Mode sombre soigné : c'est le mode d'une table le soir

APRÈS LA PARTIE
• L'historique complet de vos soirées, avec la feuille de score de chacune
• Un palmarès de fin de partie : le Visionnaire, la Tête brûlée, l'Amiral du zéro
• Les statistiques par joueur — score moyen, annonces exactes, mises 0 tenues
• Un classement all-time trié au score moyen, pas au cumul

SANS RIEN DEMANDER
• 100 % hors ligne : aucune connexion nécessaire, jamais
• Aucun compte, aucune publicité, aucun traceur, aucune donnée collectée
• Vos données restent sur votre appareil, et s'exportent en un fichier quand vous voulez
• Français, anglais, espagnol, allemand
